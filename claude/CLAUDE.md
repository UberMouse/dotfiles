- Your Bash tool runs **zsh**, not bash: my `.zshrc` with oh-my-zsh, so my aliases are live too. Script files with a bash shebang still run under bash. The trap is inline commands, where bash habits break silently or abort the whole command. To get bash semantics, use `bash -c '...'` or write a script file. Otherwise:
  - **Globs that match nothing are an error (`nomatch`), not a literal.** This bites unquoted `?`, `*` and `[...]` in URLs, jq filters (`.items[0]`), `nix` attrs and `find -name`. After a builtin (`echo`, `cd`, `export`, `[[`) it aborts every command after it; after an external command only that one fails. `2>/dev/null` does not suppress it. Quote such arguments. For a glob that may be empty, use `setopt null_glob` in a subshell; bare qualifiers like `*(N)` are OFF here (`nobareglobqual`)
  - **Unquoted `$var` is not word-split.** `cmd="ls -la"; $cmd` runs a command literally named `ls -la`. Use an array (`cmd=(ls -la); "${cmd[@]}"`) or `${=var}`
  - **Arrays are 1-indexed.** `${arr[0]}` is empty, `${arr[-1]}` is the last element, `${#arr}` is the length. Use `read -A`, not `read -a` (that errors)
  - **`[ "$a" == b ]` fails** with `= not found`, because a word starting with `=` expands to a command path. Use `[[ ... ]]` or a single `=`
  - **Reserved and tied names:** `status` is read-only (an alias of `$?`), and `path` is tied to `PATH`, so `local path=...` clobbers `PATH` inside that function. Other names to avoid for variables: `argv`, `options`, `commands`, `functions`, `aliases`
  - **Aliases shadow short names.** The oh-my-zsh git plugin defines `g`, `ga`, `gc`, `gco`, `gp`, `gl`, `gst`, `gd`, and more. Defining a function `g(){...}` is a parse error that kills the entire command before any of it runs, so give helper functions descriptive names. `xclip`, `heft` and `l` are also aliases (see `zsh.nix` in my dotfiles)
  - `echo` interprets backslash escapes by default; use `print -r --` or `printf '%s\n'` for raw output. `local x` re-declared inside a loop prints `x=<value>` to stdout. `BASH_SOURCE` and the `mapfile`/`readarray` builtins don't exist
